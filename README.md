# 🌐 Personal Portfolio

A modern and responsive personal portfolio website built with **React** and **Vite** to showcase my skills, projects, experience, and developer journey.

## 📌 About

This portfolio is designed to provide an overview of my technical skills, projects, and experience as a developer.

It includes sections for:

* 👋 Introduction
* 🧑‍💻 About Me
* 🛠️ Skills & Technologies
* 🚀 Projects
* 📬 Contact

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/NiteshKumavat/portfolio.git
```

### 2. Navigate to the project

```bash
cd portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL shown in your terminal.
